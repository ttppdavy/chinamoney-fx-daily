# China Money FX Daily

每天从中国货币网官方页面取得外汇市场数据，并把**原始响应、标准化长表和运行质量报告**保存到本仓库，便于按日期、期限和波动率类型直接比较。

## 采集范围

| 模块 | 字段 |
|---|---|
| 中间价与14:00参考汇率 | USD/CNY 中间价、14:00人民币外汇参考汇率 |
| 掉期曲线 | 完整期限的掉期点与全价 |
| 期权曲线 | ATM、25D RR、10D BF、25D BF；全部可得期限 |
| 外币隐含利率 | 美元隐含利率曲线、期限和参数 |

工作日北京时间 17:20 自动运行；USD/CNY 价格采用当日 14:00 人民币外汇参考汇率。

## 输出

```text
data/
├── raw/YYYY-MM-DD/*.json.gz   # 原始页面响应/表格快照
├── observations.csv           # 可导入 Excel 或 pandas 的历史长表
└── latest_run.json            # 本次运行的日期、时点、行数和质量结果
```

## 原则

每个页面整表读取并保存原始响应，不逐行、逐期限重复请求；页面字段或结构变化时校验失败，避免错误数据写入历史库。
