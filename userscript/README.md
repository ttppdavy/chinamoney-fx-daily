# 中国货币网外汇助手（篡改猴）

安装 `chinamoney-fx-assistant.user.js` 后，在中国货币网外汇页面右下角会出现橙色 **FX** 按钮。

## 用法

1. 先在官网选择日期、货币对、期限或曲面并点击“查询”。
2. 点击“自动采集全部页”，脚本会从第一页开始自动翻页并保存当前完整曲线；期权按页面当前选择的时点保存，不再强制 10:00。
3. “导出当前 Excel”导出所有页汇总；“官网下载 Excel”触发网站原有导出按钮，得到官方原始文件。
4. “同步 GitHub 长期历史”会读取本项目每日留档的 `daily_market_dashboard.csv`；完成回填后，它将带入 2023 年以来的数值、日变动和分位数。再点“展示 / 导出历史”即可在面板预览并导出汇总 Excel。

本地采集快照只存储在当前浏览器。长期历史由本仓库的 GitHub Actions 留档；每天更新后，在网页内点一次“同步 GitHub 长期历史”即可更新浏览器中的展示数据。
