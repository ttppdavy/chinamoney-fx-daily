# 中国货币网外汇助手（篡改猴）

安装 `chinamoney-fx-assistant.user.js` 后，在中国货币网外汇页面右下角会出现橙色 **FX** 按钮。

## 用法

1. 任意打开一个中国货币网页面，点击“一键抓取四类官网最新”。脚本会直接调用中间价、掉期、美元隐含利率和期权波动率四类官方接口，无需逐个打开页面；期权取官网当时默认的时点，并拉取 ATM、25D RR、10D BF、25D BF 四个曲面。
2. 如需保存某个页面自选条件下的数据，点击“自动采集全部页”。脚本会从第一页开始自动翻页并保存当前完整曲线。
3. “导出当前 Excel”导出所有页汇总；“官网下载 Excel”触发网站原有导出按钮，得到官方原始文件。
4. “展示 / 导出历史”会预览当前浏览器已保存的数据，并导出含日变动、历史分位和样本数的汇总 Excel。

本地采集快照只存储在当前浏览器。需要团队共享长期历史时，建议将统一导出的历史 Excel 放在行内共享盘或 SharePoint/企业网盘，由一个固定账号每日更新；同事只需下载文件或访问内网页面，无需 GitHub 账号。
