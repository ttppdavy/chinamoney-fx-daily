# 中国货币网外汇助手（篡改猴）

安装 `chinamoney-fx-assistant.user.js` 后，在中国货币网外汇页面右下角会出现橙色 **FX** 按钮。

## 用法

1. 先在官网选择日期、货币对、期限或曲面并点击“查询”。
2. 期权页面必须选择 **10:00** 后，再点“采集当前页”。脚本会把这张完整曲线保存在本浏览器。
3. “导出当前 Excel”导出眼前表格；“官网下载 Excel”触发网站原有导出按钮，得到官方原始文件。
4. 连续按日期保存后，点“展示 / 导出历史”即可下载本地汇总 Excel，其中包括每条数值的日变动、历史分位和样本数。

数据只存储在当前浏览器的篡改猴存储空间，不会自动上传。换浏览器、换电脑或清理篡改猴数据后，本地历史需要重新采集；需要长期自动留档仍建议使用本仓库的 GitHub Actions。
